# Home

A bootable appliance for [Kamerplanter](https://github.com/nolte/kamerplanter). It carries an immutable operating system and the Kamerplanter containers in one image, updates itself, and leaves nothing to patch or administer by hand.

!!! warning "Proof of concept"
    No release exists yet. The repository holds the requirements and a first proof of concept on `bootc` with Fedora; nothing here is ready for production use.

- [Getting Started](getting-started/index.md) — build the proof of concept and boot it in a virtual machine
