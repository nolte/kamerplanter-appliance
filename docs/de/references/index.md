# Referenzen

- [Konfiguration](configuration.md) — die Dateien, die die Kamerplanter-Dienste auf einer installierten Appliance konfigurieren
- [Einen Download prüfen](verify.md) — wie du prüfst, dass ein Disk-Image vom Release-Workflow dieses Repositorys stammt
- [Zugehörige Repositorys](repositories.md) — alle Kamerplanter-Repositorys und was sie für die Appliance bedeuten, auch die nur indirekt benötigten

Die Anforderungen liegen als Spezifikationen im Repository, Englisch maßgeblich, mit deutscher Übersetzung:

- [Einsatzziele](https://github.com/nolte/kamerplanter-appliance/blob/develop/spec/deployment-targets/de.md) — wo die Appliance installierbar sein muss und was jeder Ort verlangt
- [Anforderungen an die Distribution](https://github.com/nolte/kamerplanter-appliance/blob/develop/spec/distribution-requirements/de.md) — was die Basis-Distribution leisten muss
- [Release-Verteilung](https://github.com/nolte/kamerplanter-appliance/blob/develop/spec/release-distribution/de.md) — wie Releases gebaut, signiert und geprüft werden
